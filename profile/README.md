### 📦 Mes dépôts publics

**.NET et Azure**

- [azure-dotnet-starter](https://github.com/sebmafate/azure-dotnet-starter) : API minimale .NET 10 qui publie sur Azure Service Bus. Bicep, CI, aucun secret (identité managée et RBAC).
